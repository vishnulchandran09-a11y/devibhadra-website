# Devibhadra Travels website

Files:
- index.html — complete website

To publish free with GitHub Pages:
1. Create a new public GitHub repository named `devibhadra-website`.
2. Upload `index.html`.
3. In Settings → Pages, choose Deploy from branch → main → / (root).
4. Open the Pages URL to confirm it works.
5. In GitHub Pages settings, add the custom domain `devibhadra.in`.
6. In BigRock DNS, point the domain to GitHub Pages using the DNS records shown by GitHub.
